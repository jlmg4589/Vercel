# Unidad 6: Gestión de recursos en red de un sistema informático

> [!abstract] Criterios que se trabajan
> **CE6G** (configurar y explotar dominios). Contenido **BC6_9**.

> [!warning] Falta fuente: la mayor parte de BC6_9
> El Tema 6 solo menciona los dominios de forma puntual. Faltan: concepto y estructura de Active Directory (bosques, árboles, unidades organizativas), instalación de un controlador de dominio, unión de clientes al dominio, usuarios y grupos de dominio y GPO de dominio.

## 7.1 Concepto de dominio

Un **dominio** es una forma de **administración centralizada** de los recursos de una organización. Los derechos de usuario pueden aplicarse en un equipo o en un dominio ([[Sistemas Informáticos/Unidad 6 Gestión de recursos en red de un sistema informático/Apuntes/3. Derechos de usuario y directivas de grupo#3.1 Derechos de usuario\|Derechos de usuario]]).

| Modelo | Administración |
| --- | --- |
| **Grupo de trabajo** | De igual a igual, cada equipo gestiona sus recursos ([[Sistemas Informáticos/Unidad 6 Gestión de recursos en red de un sistema informático/Apuntes/2. Recursos compartidos en Windows y Samba#2.1.1 Requisitos previos\|Grupo de trabajo]]). |
| **Dominio** | Centralizada. |

## 7.2 Active Directory y GPO de dominio

- **Active Directory** es el servicio de directorio de Microsoft.
- Las **GPO no locales** se orientan a Active Directory; sus ámbitos de actuación son más variados que en las locales: **sitio**, **dominio** o **unidad organizativa** (ver [[Sistemas Informáticos/Unidad 6 Gestión de recursos en red de un sistema informático/Apuntes/3. Derechos de usuario y directivas de grupo#3.2.1 Tipos de GPO y ámbitos\|Tipos de GPO y ámbitos]]).

## 7.3 Samba como controlador de dominio

**Samba**, además de compartir archivos e impresoras mediante SMB, puede usarse como **controlador de dominio** e integrarse como **Active Directory** de Windows (ver [[Sistemas Informáticos/Unidad 6 Gestión de recursos en red de un sistema informático/Apuntes/2. Recursos compartidos en Windows y Samba#2.2 Compartir en Linux: Samba\|Samba]]).

> [!warning] Falta fuente: implantación práctica
> No hay procedimiento para configurar Samba como controlador de dominio ni para promover un Windows Server.
