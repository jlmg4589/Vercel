# Unidad 6: Gestión de recursos en red de un sistema informático

> [!abstract] Criterios que se trabajan
> **CE6D** (acceso a servidores con técnicas de conexión remota). Contenido **BC6_7**.

## 5.1 Herramientas de conexión remota

Permiten **acceder a equipos a distancia**. Usos: soporte técnico, teletrabajo, presentaciones a distancia…

| Origen | Ejemplos |
| --- | --- |
| Propias del sistema operativo | Asistencia remota y Escritorio remoto (Windows), Compartir + Remmina (Ubuntu). |
| Software de terceros | **TeamViewer**, **Chrome Remote Desktop**. |

## 5.2 Conexión remota en Windows

### 5.2.1 Configurar el equipo al que se accede

En **Propiedades del sistema** → pestaña **Acceso remoto** (versiones avanzadas de Windows):

| Área | Configuración |
| --- | --- |
| **Asistencia remota** | **Opciones avanzadas**: tiempo máximo de las conexiones y permiso de **control remoto**. |
| **Escritorio remoto** | **Permitir las conexiones remotas a este equipo** y, en **Seleccionar usuarios**, autorizar a los usuarios (por defecto, el grupo **Administradores** ya tiene permiso). |

### 5.2.2 Conectarse desde otro equipo Windows

1. Conocer la **IP privada** (misma red) o **pública** (desde Internet) del equipo remoto.
2. Abrir **Conexión a Escritorio remoto** → **Mostrar opciones**.
3. Introducir la **IP** del equipo y el **usuario** con el que conectar.

> [!tip] IP pública
> Se obtiene en cualquier web que la devuelva, buscando "cuál es mi IP" o "What is my IP".

## 5.3 Conexión remota en Linux (Ubuntu)

- **Habilitar el acceso entrante:** **Configuración** → **Compartir**, donde se establecen las opciones de acceso al equipo.
- **Cliente:** aplicación de escritorio remoto **Remmina**. Se añade un perfil de conexión (botón **+** arriba a la izquierda) con la **IP** del servidor, **usuario** y **contraseña**.

> [!note] Si falla el acceso, comprobar que:
> - El equipo está **encendido**.
> - Está **en red**.
> - El **acceso remoto** está habilitado.
> - Están habilitadas las **reglas de entrada y salida del firewall** relativas a la administración y asistencia remota de Windows.

> [!warning] Falta fuente: conexión remota por terminal
> El Tema 6 no trata la conexión remota en modo texto (SSH, PowerShell remoto) ni la configuración específica de openSUSE.
