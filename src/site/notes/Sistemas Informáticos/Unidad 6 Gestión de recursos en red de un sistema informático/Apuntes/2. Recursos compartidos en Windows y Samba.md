# Unidad 6: Gestión de recursos en red de un sistema informático

> [!abstract] Criterios que se trabajan
> **CE6A** (acceso a recursos locales y de red). Contenidos **BC6_2** (configuración de recursos compartidos) y **BC6_1** (permisos de red).

## 2.1 Compartir archivos y carpetas en Windows

### 2.1.1 Requisitos previos

Suponiendo que los usuarios tienen siempre contraseña (por seguridad), hay que asegurarse de que:

1. Los equipos están en la **misma subred lógica** establecida por el administrador de la red.
2. Están activadas la **detección de redes** y el **uso compartido de archivos**: **Configuración** → **Red e Internet** → **Centro de redes y recursos compartidos**.
3. El equipo que comparte y el que accede están en el **mismo grupo de trabajo**.
4. Hay conexión en **ambas direcciones** comprobada con `ping` (hay que conocer las IP).

```cmd
ping 192.168.1.20
```

> [!note] Grupo de trabajo
> Mecanismo de Windows para compartir recursos entre equipos **de igual a igual**. El nombre del equipo y del grupo de trabajo se consultan en **Propiedades del sistema** → pestaña **Nombre de equipo**; con **Cambiar** se pone a todos en el mismo grupo (por defecto, `WORKGROUP`).

Los permisos de red (pestaña **Compartir**, **Uso compartido avanzado**, **Conceder acceso a**) se explican en [[Sistemas Informáticos/Unidad 6 Gestión de recursos en red de un sistema informático/Apuntes/1. Permisos, herencia y listas de control de acceso#1.3 Permisos de red y permisos locales\|Permisos de red y permisos locales]].

### 2.1.2 Formas de acceder a un recurso compartido

| Forma | Procedimiento |
| :-: | --- |
| **Red** | Explorador de Windows → **Red**: aparecen los equipos accesibles; se introducen las credenciales y se accede a sus recursos compartidos. |
| **Ruta UNC** | Convención de nomenclatura universal, escrita en la barra del Explorador: `\\nombreEquipo\nombreRecurso`. |
| **Unidad asignada** | Clic secundario en **Red** → **Conectar a una unidad de red**: se indica equipo y ruta. Usa las credenciales actuales salvo que se marque **Conectar usando otras credenciales**. La unidad aparece en el panel **Carpetas** del Explorador. |

### 2.1.3 Ver los recursos compartidos de un equipo

1. En la barra del Explorador: `\\localhost`.
2. Gestión detallada: **Panel de control** → **Herramientas administrativas** → **Administrador de equipos** → **Carpetas compartidas** → **Recursos compartidos**.

### 2.1.4 Recursos compartidos ocultos (administrativos)

Windows comparte automáticamente:

| Recurso | Contenido |
| :-: | --- |
| `C$`, `D$`… | Unidades, con formato `letraUnidad$`. |
| `ADMIN$` | Directorio del sistema (normalmente `C:\Windows`). |
| `IPC$` | Tuberías de comunicación entre procesos. |

> [!tip] Recursos terminados en `$`
> Por seguridad quedan **ocultos**: no aparecen al abrir `\\localhost`, pero se puede acceder a ellos escribiendo el nombre completo con el `$` (por ejemplo, `\\equipo\C$`). Sí se ven en **Carpetas compartidas** del Administrador de equipos.

## 2.2 Compartir en Linux: Samba

**Samba** es la implementación del protocolo **SMB** en Linux para compartir archivos e impresoras en una red local con equipos Windows. También puede actuar como **controlador de dominio** e integrarse con **Active Directory** (ver [[Sistemas Informáticos/Unidad 6 Gestión de recursos en red de un sistema informático/Apuntes/7. Implantación y explotación de dominios\|7. Implantación y explotación de dominios]]).

### 2.2.1 Compartir desde el entorno gráfico

1. En **Configuración**, marcar la opción **Compartir**. Si Samba no está instalado, el sistema ofrece instalarlo.
2. Crear el recurso: **nombre** del recurso compartido, **comentario** opcional y, si procede, permitir a otras personas **crear y eliminar archivos** en la carpeta.
3. Dejar **desactivado el acceso de invitado** (por seguridad).
4. Pulsar **Crear compartición**. Si hace falta, el sistema avisa de los permisos que hay que añadir.
5. El equipo que accede debe tener activadas la **detección de redes** y el **uso compartido de archivos**.

### 2.2.2 Servicio Samba desde terminal

| Acción | Comando |
| --- | --- |
| Instalar (Ubuntu/Debian) | `sudo apt install samba samba-common smbclient` |
| Estado del servicio de ficheros | `sudo systemctl status smbd` |
| Estado del servicio de nombres NetBIOS | `sudo systemctl status nmbd` |
| Crear usuario Samba (debe existir antes como usuario local) | `sudo smbpasswd -a <usuario>` |
| Eliminar usuario Samba | `sudo smbpasswd -x <usuario>` |

```bash
sudo apt install samba samba-common smbclient
sudo systemctl status smbd
sudo systemctl status nmbd
sudo smbpasswd -a alumno
sudo smbpasswd -x alumno
```

> [!note] `smbpasswd -a` y `-x` requieren privilegios de administrador (`sudo`).

#### Equivalente en openSUSE (aula)

En openSUSE el gestor de paquetes es `zypper` y los servicios se llaman **`smb`** y **`nmb`** (no `smbd`/`nmbd`):

```bash
sudo zypper install samba samba-client
sudo systemctl enable --now smb nmb
sudo systemctl status smb nmb
sudo smbpasswd -a alumno
```
