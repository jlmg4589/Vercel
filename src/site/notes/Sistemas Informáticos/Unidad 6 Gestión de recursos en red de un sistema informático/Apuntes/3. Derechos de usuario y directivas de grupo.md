# Unidad 6: Gestión de recursos en red de un sistema informático

> [!abstract] Criterios que se trabajan
> **CE6B** (derechos de usuario y directivas de seguridad). Contenidos **BC6_1** (derechos) y **BC6_2** (permisos de acceso y directivas de seguridad).

## 3.1 Derechos de usuario

Los **derechos o privilegios** determinan las acciones que pueden realizar usuarios o grupos en un sistema, ya sea un equipo o un **dominio** (administración centralizada de los recursos de una organización).

| | Se asocian con |
| :-: | --- |
| **Permisos** | Los **objetos** (ver [[Sistemas Informáticos/Unidad 6 Gestión de recursos en red de un sistema informático/Apuntes/1. Permisos, herencia y listas de control de acceso\|1. Permisos, herencia y listas de control de acceso]]). |
| **Derechos** | Los **usuarios**. |

Como con los permisos, al asignar derechos a un grupo se asignan automáticamente a todos sus miembros.

| Tipo | Qué determina |
| --- | --- |
| **Derechos de inicio de sesión** | Quién y de qué modo inicia sesión en el sistema. |
| **Privilegios específicos** | Lo que puede hacer el usuario una vez dentro: hacer copias de seguridad de archivos y directorios, apagar el sistema… |

> [!note] Derechos frente a permisos
> Los **derechos prevalecen** sobre los permisos de los objetos. Ejemplo: un usuario sin permisos sobre un objeto puede tener el derecho de cambiar los permisos de ese objeto.

### 3.1.1 Administrar derechos en Windows

- **Herramientas administrativas** → **Directiva de seguridad local** (`secpol.msc`) → **Configuración de seguridad** → **Directivas locales** → **Asignación de derechos de usuario**.
- O con el **Editor de directivas de grupo local** (`gpedit.msc`, ediciones Pro/Enterprise/Education de Windows 10/11): **Configuración del equipo** → **Configuración de Windows** → **Configuración de seguridad** → **Directivas locales** → **Asignación de derechos de usuario**.

> [!info] Fuentes
> - [Microsoft Learn – User Rights Assignment](https://learn.microsoft.com/en-us/previous-versions/windows/it-pro/windows-10/security/threat-protection/security-policy-settings/user-rights-assignment)

> [!warning] Falta fuente: derechos y privilegios en Linux
> El Tema 6 no trata el equivalente en Linux (por ejemplo, `sudo`/grupos administrativos). Ver la [[Sistemas Informáticos/Unidad 4 Sistemas operativos. Gestión de usuarios y procesos/Apuntes/1. Usuarios y grupos locales en Linux y Windows#1.1.3 Cambiar de usuario o ejecutar comandos con privilegios\|UD4: ejecutar comandos con privilegios]].

## 3.2 Directivas de seguridad y GPO

Las **directivas de seguridad** son un conjunto de reglas para administrar usuarios y equipos. Se definen mediante **objetos de directiva de grupo (GPO)**, que contienen parámetros con políticas del sistema y permiten centralizar permisos, bloqueos o controles sobre usuarios y equipos.

> [!example] Usos típicos de una GPO
> - Configurar el entorno gráfico.
> - Automatizar tareas.
> - Impedir que un usuario instale o desinstale programas.
> - Fortalecer las contraseñas de inicio de sesión.
> - Evitar el uso de memorias USB.

### 3.2.1 Tipos de GPO y ámbitos

| Tipo | Ámbito |
| :-: | --- |
| **GPO locales** | Equipos que **no** forman parte de un dominio. Actúan en el propio equipo. |
| **GPO no locales** | Orientadas a **Active Directory**; ámbitos: **sitio**, **dominio** o **unidad organizativa** (ver [[Sistemas Informáticos/Unidad 6 Gestión de recursos en red de un sistema informático/Apuntes/7. Implantación y explotación de dominios\|7. Implantación y explotación de dominios]]). |

En esta unidad se trabajan las **GPO locales**, que se gestionan con el **Editor de directivas de grupo local** (ediciones Pro/Enterprise/Education de Windows 10/11) o ejecutando:

```cmd
gpedit.msc
```

Para aplicarlas de forma más pormenorizada se usa la **MMC** ([[Sistemas Informáticos/Unidad 6 Gestión de recursos en red de un sistema informático/Apuntes/3. Derechos de usuario y directivas de grupo#3.4 Seguridad a nivel de usuarios y equipos con MMC\|#3.4 Seguridad a nivel de usuarios y equipos con MMC]]).

### 3.2.2 Estructura de las GPO locales

| Rama | Cuándo se aplica |
| --- | --- |
| **Configuración del equipo** | En el **arranque** del sistema. |
| **Configuración de usuario** | En cada **inicio de sesión** del usuario. |

Cada rama se divide en (con políticas distintas):

| Parte | Contenido |
| --- | --- |
| **Configuración de software** | Configuración del software instalado e instalación automática de software nuevo. |
| **Configuración de Windows** | Entorno de Windows: configuración de seguridad (asignación de derechos de usuario), ejecución de *scripts*… |
| **Plantillas administrativas** | Políticas de configuración del equipo: inicio y apagado, panel de control, red, componentes de Windows… Es la categoría **más importante** por la cantidad de directivas. |

> [!tip] Revisar las GPO establecidas
> En **Plantillas administrativas** (de equipo o de usuario) se puede listar **Todos los valores** para controlar las GPO configuradas.

### 3.2.3 Comprobar las directivas aplicadas: `gpresult`

| Objetivo | Comando |
| --- | --- |
| Políticas aplicadas a un usuario concreto (detallado) | `gpresult /USER usuario /V` |
| Resumen de las políticas aplicadas al sistema | `gpresult /r` |

```cmd
gpresult /USER alumno /V
gpresult /r
```

## 3.3 Plantillas administrativas

Permiten definir la configuración del **registro** de Windows para administrar aplicaciones o características del sistema y también aplicaciones de terceros (Office, Chrome, Adobe…).

> [!note] Se pueden **agregar o quitar** plantillas de las aplicaciones sobre las que se quieran establecer GPO.

## 3.4 Seguridad a nivel de usuarios y equipos con MMC

La **consola de administración de Microsoft (MMC)** permite aplicar directivas de seguridad a usuarios o equipos de forma **selectiva** y crear **consolas personalizadas** que reúnan las herramientas administrativas que elija el administrador.

Procedimiento para aplicar una GPO de forma selectiva:

1. Escribir `MMC` en el cuadro de búsqueda de Windows.
2. Menú **Archivo** → **Agregar o quitar complemento**.
3. Seleccionar **Editor de objetos de directiva de grupo**.
4. **Agregar** inicia un asistente: pulsar **Examinar** para indicar dónde se aplica.
5. Elegir destino:
   - Pestaña **Equipos**: **Este equipo** u **Otro equipo**.
   - Pestaña **Usuarios**: usuarios o grupos a los que aplicar la GPO.
6. Finalizar el asistente y aceptar: la consola muestra el nuevo complemento.
7. **Guardar** la consola.

> [!tip] Con MMC se administran de forma centralizada, rápida y cómoda distintas GPO para grupos, usuarios y equipos.
