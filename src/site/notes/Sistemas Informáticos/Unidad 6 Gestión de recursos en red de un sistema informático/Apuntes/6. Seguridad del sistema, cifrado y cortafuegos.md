## 6.2 Cifrado

Las herramientas de cifrado garantizan la **confidencialidad, autenticidad e integridad** de los datos convirtiéndolos a un formato codificado.

### 6.2.1 Windows: EFS

**EFS** (*Encrypting File System*) cifra sobre **NTFS**.

- Cifra los archivos **individualmente** y los vincula al **usuario que los cifró**: solo ese usuario puede usarlos.
- **No es compatible con la compresión.**
- Uso: **Propiedades** del archivo → pestaña **General** → **Avanzados** → **Cifrar contenido para proteger datos**.

> [!note] Comportamiento de EFS
> - Mover archivos a una carpeta cifrada (en NTFS) los **cifra**; sacarlos no los descifra.
> - Se **descifran** si se mueven a un volumen que **no es NTFS**.
> - Otros usuarios con permisos pueden **listarlos o eliminarlos**.

### 6.2.2 Windows: BitLocker

Cifra **volúmenes enteros** para asegurar privacidad e integridad. Es más potente que EFS:

- Es **independiente de los usuarios**.
- Puede usar el chip **TPM** (*Trusted Platform Module*), así como una **clave** o **tarjeta inteligente con PIN** para el acceso.
- Uso: **Panel de control** → **Cifrado de unidad BitLocker** → **Activar BitLocker** en el volumen.

| | EFS | BitLocker |
| --- | --- | --- |
| Alcance | Archivos y carpetas | Volumen completo |
| Vinculado a | Usuario que cifra | Independiente del usuario |
| Requisitos/apoyos | NTFS; incompatible con compresión | TPM, clave o tarjeta con PIN |

### 6.2.3 GNU/Linux: GPG y Seahorse

**GPG** (*GNU Privacy Guard*) usa cifrado **simétrico y asimétrico**. Ubuntu integra **Seahorse**, que administra claves y contraseñas, incluidas las GPG.

1. Crear las claves: Seahorse → **Archivo** → **Nuevo** → **Clave PGP**.
2. Integrar con el explorador **Nautilus**:

```bash
sudo apt update
sudo apt install seahorse-nautilus
```

3. Clic secundario sobre el archivo o carpeta → **Cifrar**.

> [!warning] Al cifrar se genera un archivo `.gpg`; por seguridad hay que **eliminar el original sin cifrar**.

En openSUSE (aula) se instala con `zypper`:

```bash
sudo zypper install seahorse seahorse-nautilus
```

> [!info] Fuentes
> - [openSUSE Software – seahorse-nautilus](https://software.opensuse.org/package/seahorse-nautilus)

## 6.3 Administración y análisis de la red

Cuanto mayor es la infraestructura de red, más complejo es analizar su tráfico. Se necesitan herramientas que **monitoricen la red de forma unificada** para:

- Estudiar la red en un momento concreto y a largo plazo.
- Valorar la optimización de la infraestructura.
- Detectar tráfico malintencionado.

> [!example] Pandora FMS
> https://pandorafms.com. Orientada a empresas: monitoriza toda la red corporativa sobre distintos SO, aplicaciones, protocolos, virtualización, bases de datos… Tiene versión de pago (**Enterprise**) y libre (**Opensource**).

## 6.4 Cortafuegos

Un cortafuegos (*firewall*) **controla el tráfico entrante y saliente** de una red: filtra las amenazas externas y evita accesos no autorizados.

**Capacidades de filtrado:**

- De **paquetes** por direcciones **IP o MAC**.
- De **aplicaciones**, según el **número de puerto**.
- De **direcciones URL**.

Suelen usar **NAT** para ocultar las direcciones privadas de los equipos protegidos, de modo que un atacante externo no las conozca.

### 6.4.1 Tipos de cortafuegos

| Tipo | Descripción |
| --- | --- |
| **Dedicado** | Hardware específico cuya única función es analizar el tráfico a gran velocidad. |
| **Integrado** | En dispositivos hardware con varias funciones, como los routers SoHo. |
| **Software** | Aplicaciones del SO o de terceros: **de servidor** (en SO en red, con ámbito sobre los clientes que gobierna) o **personal** (filtra el tráfico entre el equipo y el resto de la red). |

### 6.4.2 Política de seguridad

Antes de configurar el cortafuegos se decide su política:

| Política | Comportamiento |
| :-: | --- |
| **Denegar por defecto** | Prohíbe todo lo que no esté autorizado explícitamente. |
| **Aceptar por defecto** | Permite todo salvo lo prohibido explícitamente. |

### 6.4.3 Cortafuegos en Windows

**Panel de control** → **Firewall de Windows Defender** → **Permitir una aplicación o una característica a través de Firewall de Windows Defender** (ejemplo con el servidor FTP en [[Sistemas Informáticos/Unidad 6 Gestión de recursos en red de un sistema informático/Apuntes/4. Servidores de ficheros, impresión y aplicaciones#4.2.1 Servidor FTP en Windows (IIS)\|Servidor FTP en Windows]]). Para la conexión remota hay que habilitar las reglas de entrada y salida de administración y asistencia remota ([[Sistemas Informáticos/Unidad 6 Gestión de recursos en red de un sistema informático/Apuntes/5. Técnicas de conexión remota\|5. Técnicas de conexión remota]]).

### 6.4.4 Cortafuegos en Linux: UFW y Gufw

- **UFW** (*Uncomplicated Firewall*, "cortafuegos sin complicaciones") es una interfaz sencilla para **iptables**/**nftables**, herramientas de espacio de usuario que configuran **netfilter**, el filtrado de paquetes integrado en el kernel.
- **Gufw** es su interfaz gráfica (hay que instalarla). Se abre buscando **Configuración del cortafuegos** (*Firewall Configuration*) en el menú de aplicaciones.
- Se **habilita** el cortafuegos y se añaden **reglas** de forma **preconfigurada, simple o avanzada** según la pestaña.

> [!tip] Conviene leer el manual de usuario de Gufw para crear las reglas en el **orden correcto** y del **tipo adecuado**.
