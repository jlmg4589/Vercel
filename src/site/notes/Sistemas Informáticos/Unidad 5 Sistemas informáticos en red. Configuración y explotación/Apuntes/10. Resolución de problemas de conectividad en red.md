# Unidad 5: Sistemas informáticos en red. Configuración y explotación

> [!abstract] Criterios que se trabajan
> **CE5G** (verificación del funcionamiento de la red con comandos y herramientas). Contenidos **BC5_4** (resolución de problemas de conectividad, herramientas de diagnóstico) y **BC5_6**.

## 10.1 Tipos de mantenimiento

El mantenimiento de la infraestructura de red y de los sistemas en red se aborda desde tres ámbitos:

| Ámbito | Descripción |
| --- | --- |
| **Predictivo** | Intenta pronosticar un fallo futuro; se suelen usar utilidades de diagnóstico. |
| **Preventivo** | Se sigue un **Plan de mantenimiento preventivo** con las acciones, técnicas y procedimientos que hay que realizar y su frecuencia. |
| **Correctivo** | Se repara el objeto del fallo siguiendo un **Plan de mantenimiento correctivo**, que establece el método para diagnosticar y resolver averías. |

> [!tip] Secuencia orientativa de diagnóstico
> Con lo visto en la fuente: `ping` permite comprobar primero el propio adaptador, después otros equipos de la red local y, por último, equipos de fuera (Internet), "descartando errores y localizando el problema". Si falla fuera de la red local, `traceroute`/`tracert` muestra en qué router se corta la ruta.
> ```bash
> ip a                  # ¿tiene IP la interfaz?
> ping 127.0.0.1        # pila TCP/IP local
> ping <puerta_enlace>  # red local
> ping 8.8.8.8          # salida a Internet
> ping www.google.com   # resolución DNS
> traceroute 8.8.8.8    # dónde se corta la ruta
> ```
> El orden concreto de los pasos y las direcciones son una propuesta (de dentro hacia fuera, capa a capa). En Windows: `ipconfig`, `ping` y `tracert`.
