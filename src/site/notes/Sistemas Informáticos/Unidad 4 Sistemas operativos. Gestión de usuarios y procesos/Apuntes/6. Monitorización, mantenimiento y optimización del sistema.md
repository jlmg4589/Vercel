# Unidad 4: Sistemas operativos. Gestión de usuarios y procesos

> [!abstract] Criterios que se trabajan
> **CE4F** (monitorización), **CE4G** (utilidades de mantenimiento y optimización) y **CE4H** (necesidades del sistema y desarrollo de aplicaciones). Contenido **BC4_7**.

## 6.1 Monitorización en Linux

Además de [[Sistemas Informáticos/Unidad 4 Sistemas operativos. Gestión de usuarios y procesos/Apuntes/4. Procesos. Estados, planificación y comandos#4.4.1 ps\|ps]] y [[Sistemas Informáticos/Unidad 4 Sistemas operativos. Gestión de usuarios y procesos/Apuntes/4. Procesos. Estados, planificación y comandos#4.4.2 pstree y top\|top]], estos comandos dan información sobre el rendimiento:

| Comando | Información |
| :-: | --- |
| `uptime` | Hora, tiempo en activo, n.º de usuarios y carga a 1, 5 y 15 minutos (equivale a la 1.ª línea de `top`). |
| `free` | Memoria libre y usada. |
| `vmstat` | Detalle de memoria RAM, memoria virtual, intercambio RAM-disco, interrupciones y procesador. |
| `df` | Porcentaje de uso de las unidades de almacenamiento. |
| `w` | Usuarios conectados y qué hacen (parecido a `who`). |

```text
vmstat [tiempo [actualizaciones]]
```

- `tiempo`: segundos entre actualizaciones.
- `actualizaciones`: número de muestras.

```bash
vmstat 3 5
```

## 6.2 Monitorización en Windows

**Administrador de tareas**:

| Pestaña | Permite analizar |
| :-: | --- |
| **Rendimiento** | Uso de CPU, procesos y subprocesos activos, memoria RAM (en uso, disponible, paginada), discos, tráfico de los adaptadores de red… |
| **Usuarios** | % de CPU, memoria, disco y red de cada usuario, desglosado por aplicaciones. |
| **Detalles** y **Servicios** | Aplicaciones en segundo plano y servicios de Windows. |

## 6.3 Aplicaciones para el mantenimiento y la optimización

Mejoran la funcionalidad, la manejabilidad y la seguridad del sistema.

| Categoría | Finalidad | Ejemplos de la fuente |
| --- | --- | --- |
| **Actualización y control de drivers** | El SO actualiza los drivers, pero una incompatibilidad puede dejar el hardware en estado inconsistente; estas aplicaciones avisan de actualizaciones. | Drivers Cloud, Driver Booster |
| **Sincronización, copias e imágenes** | Automatizar copias de seguridad. | EaseUS Todo Backup Free (copias), Clonezilla (imágenes), FreeFileSync (sincronización) |
| **Antivirus** | Detectar y eliminar software malicioso (también antispyware, firewall, antimalware, antipop-ups). | Avira, Panda, Bitdefender, Kaspersky, AVG, Avast |
| **Optimización del sistema** | Cuidar descargas, instalaciones y desinstalaciones, carpetas temporales… | CCleaner (Windows), Stacer (Linux) |
