## 4.1 Nombres de dispositivos en Linux

Linux integra discos y particiones en su árbol de directorios. Una partición con sistema de archivos se **anexa** al árbol a través de un directorio llamado **punto de montaje**.

Los dispositivos se administran en `/dev`. Sintaxis del nombre:

`/dev/<id_dispositivo><letra_orden><número_partición>`

| Nombre | Dispositivo |
| --- | --- |
| `/dev/hd*` | Discos IDE (nomenclatura obsoleta: hoy los IDE/PATA también aparecen como `sd*`). |
| `/dev/sd*` | Discos SCSI, SATA (y PATA) y unidades USB (flash o discos externos). |
| `/dev/nvme*` | SSD NVMe: `/dev/nvme0n1` (disco), `/dev/nvme0n1p1` (primera partición). |
| `/dev/tty*` | Consolas o terminales físicos. |
| `/dev/ttyS*` | Puertos serie. |
| `/dev/sr*`, `/dev/scd*` | Unidades de CD o DVD. |

Ejemplos: `/dev/hda` (primer disco IDE), `/dev/sdb` (segundo disco SCSI/SATA/USB), `/dev/sdc2` (segunda partición del tercer disco), `/dev/ttyS0` (primer puerto serie).

> [!note] Consolas
> **Ctrl + Alt + F1…F6** cambia entre consolas de texto; **Ctrl + Alt + F7** vuelve al entorno gráfico en muchas distribuciones (en otras, como Ubuntu o Fedora con GDM, la sesión gráfica está en **F1** o **F2**).

## 4.2 Montaje y desmontaje

### 4.2.1 `mount`

Monta cualquier sistema de archivos reconocible por el núcleo en un punto de montaje. Los sistemas de archivos se montan a mano o durante el arranque.

`mount [opciones] [tipo] [dispositivo] [punto_de_montaje]`

| Opción | Efecto |
| :-: | --- |
| `-a` | Monta lo indicado en `/etc/fstab` (salvo entradas con `noauto`). |
| `-v` | Información del proceso. |
| `-w` | Lectura y escritura. |
| `-r` | Solo lectura. |
| `-t tipo` | Tipo: `ext2`, `ext3`, `ext4`, `xfs`, `btrfs`, `ntfs` (o `ntfs3`), `exfat`, `nfs`, `iso9660`, `msdos`, `vfat`, `hfs`, `hfsplus`, `cifs` (sustituye a `smbfs`). Opcional: `mount` intenta averiguarlo. |

`mount` sin argumentos lista lo montado. Los escritorios montan automáticamente, por ejemplo, un pendrive al conectarlo (la fuente cita Ubuntu).

Pasos para montar (por defecto, solo root):

1. Identificar la partición:
   - `lsblk`: dispositivos de bloques (nombre, tipo, punto de montaje, tamaño). `lsblk --fs` muestra el sistema de archivos, etiquetas y UUID.
   - `df`: dispositivos o particiones y su uso.
2. Crear el punto de montaje si no existe.
3. Montar.

```bash
lsblk --fs
mkdir /home/luis/pendrive
sudo mount -t vfat /dev/sdb1 /home/luis/pendrive
```

> [!note] Ejemplo reconstruido
> La fuente muestra este ejemplo como captura (pendrive `/dev/sdb1` en `/home/luis/pendrive`). La sintaxis es correcta; `vfat` corresponde a un pendrive FAT32 (si es exFAT o NTFS, usar `exfat` o `ntfs`, u omitir `-t`).

### 4.2.2 `umount`

Hay que desmontar para dejar de usar o extraer un dispositivo: `umount <dispositivo>` o `umount <punto_de_montaje>`.

```bash
umount /dev/sdb1
umount /home/luis/pendrive
```

### 4.2.3 Montaje permanente: `/etc/fstab`

Se edita como root (`sudo nano /etc/fstab`). Cada línea tiene seis columnas:

| Campo | Significado |
| --- | --- |
| `<file system>` | Partición (nombre, `LABEL=` o `UUID=`). |
| `<dir>` | Punto de montaje. |
| `<type>` | Tipo de sistema de archivos. |
| `<options>` | Opciones de montaje (ver tabla siguiente). |
| `<dump>` | `0` o `1`: si se hacen o no copias de seguridad. |
| `<pass>` | Orden de comprobación con `fsck`: `0` no se comprueba, `1` solo para `/`, `2` para el resto. |

| Opción | Efecto |
| --- | --- |
| `auto` | Se monta en el arranque (por defecto). |
| `noauto` | Solo manualmente. |
| `ro` / `rw` | Solo lectura / lectura-escritura. |
| `user` | Cualquier usuario puede montarlo; solo quien lo montó puede desmontarlo (implica `noexec`, `nosuid`, `nodev`). |
| `users` | Cualquier usuario puede montarlo **y desmontarlo**. |
| `group` | Puede montarlo un usuario que pertenezca al grupo del dispositivo. |
| `nouser` | Solo root. |
| `defaults` | Opciones predeterminadas: `rw`, `suid`, `dev`, `exec`, `auto`, `nouser`, `async`. |

Ejemplo ilustrativo:

```bash
# <file system>          <dir>      <type> <options> <dump> <pass>
UUID=<código_UUID>       /mnt/datos ext4   defaults  0      2
LABEL=<nombre-etiqueta>  /mnt/usb   vfat   noauto,user 0    0
```

Antes de reiniciar, conviene comprobar el fichero con `sudo findmnt --verify` (o montar con `sudo mount -a`).

> [!info] Fuentes
> - [mount(8)](https://man7.org/linux/man-pages/man8/mount.8.html) y [fstab(5)](https://man7.org/linux/man-pages/man5/fstab.5.html)

### 4.2.4 Etiquetas y UUID

Los nombres `/dev/sdX` pueden confundirse, por eso es mejor identificar las particiones por:

1. **Etiqueta**, con GParted (partición desmontada) o por comandos:

| Sistema de archivos | Comando |
| --- | --- |
| NTFS | `ntfslabel <partición> <etiqueta>` |
| FAT | `fatlabel <partición> <etiqueta>` |
| ext2/3/4 | `e2label <partición> <etiqueta>` o `tune2fs -L <etiqueta> <partición>` |
| swap | `swaplabel -L <etiqueta> <partición>` |

2. **UUID** (identificador único universal), asignado al **formatear**.

Ambos se consultan con `lsblk --fs` y se usan en `fstab` como `LABEL=` o `UUID=`.

## 4.3 Particionar en Linux

La mayoría de tareas requieren privilegios de **root**. Herramientas conocidas: `fdisk`, `gdisk`, Discos de GNOME, `parted` y **GParted**. Se estudian `fdisk`, Discos de GNOME y GParted.

### 4.3.1 Discos de GNOME (*GNOME Disks*)

Incluida en Ubuntu con GNOME como **Discos**. A la izquierda, los dispositivos; a la derecha, la información de la partición seleccionada. Permite:

- Desmontar, eliminar y establecer opciones de la partición.
- Formatear, editar y redimensionar.
- Comprobar y reparar el sistema de archivos.
- Crear y restaurar una imagen.
- Probar el rendimiento.

### 4.3.2 GParted

Interfaz gráfica sencilla: se elige el disco y en el centro se ve un esquema con las particiones y su ocupación. Sobre una partición o espacio sin asignar se puede:

- Crear particiones en espacio no particionado, eliminarlas.
- Redimensionar o mover (reducir por el principio o por el final; ampliar si hay espacio libre).
- Copiar y pegar particiones en otros discos.
- Formatear y asignar un nombre.

Procedimiento:

1. Un disco "limpio" necesita **tabla de particiones**: menú **Dispositivo → Crear tabla de particiones** → `msdos` (MBR) o `gpt`.
2. Seleccionar el espacio sin asignar → **Partición → Nueva** → tamaño, sistema de archivos, etiqueta y tipo (**primaria, extendida o lógica**).
3. En **GPT** solo hay particiones **primarias**.

### 4.3.3 `fdisk`

`fdisk <disco | partición>`. Al empezar puede avisar, por ejemplo, de que un disco de **más de 2 TB** debería usar **GPT**. Funciona con teclas de menú:

| Tecla | Acción |
| :-: | --- |
| `m` | Lista todas las acciones. |
| `n` | Nueva partición. |
| `t` | Cambiar el tipo (p. ej. `fd`, *Linux raid auto*). |
| `w` | **Guardar** y salir. |

> [!warning] Guardar antes de salir
> Si no se guarda con `w`, los cambios en la tabla de particiones no tienen efecto.

Otras teclas del menú de `fdisk`: `p` (mostrar la tabla), `d` (borrar una partición), `g` / `o` (crear una tabla GPT / MBR vacía), `l` (listar tipos) y `q` (salir **sin** guardar). En tablas GPT el tipo *Linux RAID* se elige por su nombre o alias (`raid`) en lugar de `fd`.

> [!info] Fuentes
> - [fdisk(8)](https://man7.org/linux/man-pages/man8/fdisk.8.html)

## 4.4 Formatear en Linux: `mkfs`

`mkfs [opciones] [-t tipo] dispositivo`

- **opciones:** etiqueta, formato rápido, tamaño de clúster… Dependen del constructor (consultar `man`).
- **`-t` tipo:** `ext2`, `ext3`, `ext4`, `vfat` (msdos), `ntfs`…
- **dispositivo:** normalmente una partición, que debe estar **desmontada**.

`mkfs` es un ***front-end***: llama al constructor `mkfs.ext2`, `mkfs.ext3`, `mkfs.ext4`, `mkfs.vfat`, `mkfs.ntfs`…, algunos de ellos enlaces simbólicos a `mke2fs`, `mkntfs` o `mkfs.fat`. Son equivalentes:

```bash
sudo mkfs.ntfs /dev/sdc1
sudo mkntfs /dev/sdc1
sudo mkfs -t ntfs /dev/sdc1
```

## 4.5 Administrador de discos de Windows

Ruta: **Panel de control → Herramientas administrativas** (en Windows 11, **Herramientas de Windows**) **→ Administración de equipos → Almacenamiento → Administración de discos**. Atajos: clic derecho en Inicio → **Administración de discos**, o `diskmgmt.msc`.

Muestra cada disco y sus particiones (tamaño, capacidad, espacio libre y usado) y permite **crear, formatear y eliminar particiones** y **cambiar etiquetas o letras** de unidad. Los volúmenes dinámicos (RAID) se ven en [[Sistemas Informáticos/Unidad 3 Sistemas operativos. Gestión de archivos y almacenamiento/Apuntes/5. Mantenimiento de discos, RAID y volúmenes#5.5 Discos dinámicos y volúmenes en Windows\|Discos dinámicos]].
