# Unidad 3: Sistemas operativos. Gestión de archivos y almacenamiento

> [!abstract] Criterios que se trabajan
> **CE3C** (herramientas gráficas y comandos para localizar información en el sistema de archivos). Contenido **BC3_1** (gestión de sistemas de archivos mediante comandos y entornos gráficos).

## 3.1 Sintaxis de los comandos y listado con `ls`

Sintaxis general en Linux: `comando [opciones] [argumentos]`. Opciones y argumentos pueden ser opcionales y **distinguen mayúsculas y minúsculas**.

`ls [opciones]` lista el contenido de un directorio o la información de un archivo.

| Opción | Efecto |
| :-: | --- |
| `-l` | Formato largo. |
| `-t` | Ordena por fecha de modificación. |
| `-r` | Invierte el orden. |
| `-R` | Lista recursivamente cada directorio. |
| `-i` | Muestra el número de i-nodo. |
| `-a` | Muestra los archivos ocultos. |
| `-h` | Tamaño en K, M, G… |
| `-s` | Tamaño en bloques. |
| `-S` | Ordena por tamaño (de mayor a menor). |
| `--color` | Activada por defecto; colorea según el tipo de archivo. |

> [!note] Entradas ocultas `.` y `..`
> Todo directorio tiene dos entradas ocultas creadas automáticamente: `.` (el propio directorio) y `..` (el padre).

## 3.2 Tipos de ficheros en Linux

En Linux **todo elemento físico (discos, impresoras) o lógico (directorios, enlaces) se representa como un archivo**, lo que estandariza su gestión.

- **Regulares:** ficheros ordinarios. Incluyen los **ejecutables** (con algún permiso de ejecución y código ejecutable).
- **Directorios:** guardan en su bloque de datos el **número de i-nodo y el nombre** de los archivos que contienen. Ejemplo de la fuente: `.` con i-nodo 9437185 y 14 enlaces duros; `..` (la raíz) con i-nodo 2 y 19 enlaces duros.
- **Enlaces** (ver [[Sistemas Informáticos/Unidad 3 Sistemas operativos. Gestión de archivos y almacenamiento/Apuntes/3. Gestión de archivos por comandos y entorno gráfico#3.2.1 Enlaces duros y simbólicos\|#3.2.1 Enlaces duros y simbólicos]]).
- **Dispositivos** (en `/dev`):
  - **Por caracteres:** sin sistema de archivos; transfieren carácter a carácter (impresoras, teclados, terminales).
  - **Por bloques:** almacenan la información en bloques (discos duros, cintas, unidades flash).

| Tipo de fichero | Carácter en `ls -l` |
| --- | :-: |
| Fichero regular | `-` |
| Directorio | `d` |
| Enlace simbólico | `l` |
| Dispositivo por caracteres | `c` |
| Dispositivo por bloques | `b` |

### 3.2.1 Enlaces duros y simbólicos

| | Enlace duro | Enlace simbólico (blando) |
| --- | --- | --- |
| Qué es | Otro **nombre** para el **mismo i-nodo** (en el mismo u otro directorio). | Un **i-nodo nuevo** que guarda la **ruta** al archivo destino (en el propio i-nodo si ocupa < 60 B; si no, en un bloque de un *extent*). |
| Sobre | Cualquier fichero salvo directorios. | Cualquier archivo. |
| Alcance | Solo dentro del **mismo sistema de archivos** (misma partición). | Otros sistemas de archivos, particiones y equipos en red. |
| Si se borra el original | Los datos siguen accesibles (mismo i-nodo). | El enlace se **rompe**. |
| Comando | `ln fichero fichero_enlace` | `ln -s fichero fichero_enlace` |

## 3.3 Operaciones con archivos y directorios

### 3.3.1 Eliminar ficheros: `rm`

`rm [opciones] lista_de_ficheros`

| Opción | Efecto |
| :-: | --- |
| `-i` | Pide confirmación. |
| `-r`, `-R` | Borrado recursivo de directorios. |
| `-f` | Fuerza el borrado aunque esté protegido contra escritura. |

**Comodines:** `*` sustituye cualquier cadena; `?` sustituye un carácter.

### 3.3.2 Crear y eliminar directorios: `mkdir`, `rmdir`

`mkdir [opciones] directorios`

| Opción | Efecto |
| :-: | --- |
| `-m` | Establece permisos como `chmod` (ver [[Sistemas Informáticos/Unidad 4 Sistemas operativos. Gestión de usuarios y procesos/Apuntes/3. Permisos locales, máscara y perfiles de usuario#3.3 Modificación de permisos. chmod\|UD4: chmod]]). |
| `-p` | Crea los directorios padre si no existen. |
| `-v` | Mensaje por cada directorio creado. |

Para borrar: `rm -r` o `rmdir [opciones] argumentos` (`-p` elimina también los predecesores; `-v` informa).

```bash
rmdir -p dir1/dir1_1/dir1_1_1   # borra desde el final (dir1_1_1) hacia arriba hasta dir1; deben estar vacíos
rm -r dir1/dir1_1               # borra dir1_1 y todo lo que cuelga de él (hacia los hijos)
```

### 3.3.3 Copiar: `cp`

`cp [opciones] origen... destino`. Por defecto **sobrescribe** en el destino los archivos con el mismo nombre.

| Opción | Efecto |
| :-: | --- |
| `-i` | Pide confirmación antes de sobrescribir. |
| `-r`, `-R` | Copia recursiva de directorios. |
| `-l` | Crea enlaces duros en vez de copiar. |
| `-s` | Crea enlaces simbólicos en vez de copiar. |
| `-u` | Solo copia los archivos más recientes que los del destino. |
| `-v` | Informa de la copia. |

### 3.3.4 Mover o renombrar: `mv`

`mv [opciones] origen... destino`. Igual que `cp`, pero los originales desaparecen.

- `-i`: interactivo; avisa si se va a sobrescribir (en algunas distribuciones avisa aunque no se ponga).
- `-u`: solo mueve si el origen es más reciente que el destino con el mismo nombre.

## 3.4 Ver el contenido de archivos

`cat [opciones] [archivos] [{ > | >> | < | << } archivo]` concatena archivos y los muestra. El contenido debe ser **texto ASCII** para ser legible.

| Opción | Efecto |
| :-: | --- |
| `-A` | Muestra todo, incluidos los caracteres especiales. |
| `-b` | Numera las líneas no vacías. |
| `-n` | Numera todas las líneas. |

Con `>` (sobrescribe o crea) y `>>` (añade o crea) se crean archivos pequeños rápidamente: se escribe el texto y se termina con **Ctrl + D**.

```bash
cat > a.txt          # escribir texto y pulsar Ctrl+D
cat a.txt b.txt > ab.txt   # fusionar dos archivos en uno
```

| Comando | Uso |
| --- | --- |
| `more archivos` | Muestra por páginas. |
| `less archivos` | Como `more`, más versátil; ideal para ficheros grandes. |
| `head [-n] archivos` | Primeras *n* líneas (10 por defecto). |
| `tail [-n] archivos` | Últimas *n* líneas (10 por defecto). |

## 3.5 Contar y ordenar

### 3.5.1 `wc`

`wc [opciones] ficheros` muestra por defecto líneas, palabras y bytes.

| Opción | Cuenta |
| :-: | --- |
| `-l` | Líneas. |
| `-w` | Palabras. |
| `-c` | Bytes. |
| `-L` | Longitud de la línea más larga. |

### 3.5.2 `sort`

`sort [opciones] [-t delimitador] [-k campo] archivos`. Ordena según la **configuración regional** (*locale*): con `LC_ALL=C` sigue el **código ASCII** (las minúsculas van después de las mayúsculas); con un *locale* como `es_ES.UTF-8` el orden es alfabético y mezcla mayúsculas y minúsculas. [Tabla ASCII](https://es.wikipedia.org/wiki/ASCII#Caracteres_imprimibles_ASCII).

| Opción | Efecto |
| :-: | --- |
| `-f` | Ignora mayúsculas/minúsculas. |
| `-r` | Orden inverso. |
| `-n` | Orden numérico. |
| `-u` | Elimina repetidos. |
| `-t` | Delimitador de campos. |
| `-k` | Campo por el que ordenar (por defecto, separan espacios, tabuladores y fin de línea). |

## 3.6 Entrada y salida estándar. Redirecciones

Cada comando tiene asociados tres flujos con su **descriptor de fichero**:

| Nombre | Descriptor | Destino por defecto |
| --- | :-: | --- |
| Entrada estándar (`stdin`) | 0 | Teclado |
| Salida estándar (`stdout`) | 1 | Pantalla |
| Error estándar (`stderr`) | 2 | Pantalla |

Los mensajes de error y avisos se envían por la **salida de error estándar** (`stderr`), no por la salida estándar.

| Operador | Efecto |
| :-: | --- |
| `>` o `1>` | Salida estándar a fichero (crea o **sobrescribe**). |
| `>>` | Salida estándar a fichero (crea o **añade**). |
| `<` | Fichero como entrada estándar. |
| `<< delimitador` | Introduce texto hasta una línea que solo contenga el delimitador. |
| `2>` / `2>>` | Salida de error a fichero (sobrescribe / añade). |
| `&>` / `&>>` | Salida estándar **y** de error al mismo fichero (sobrescribe / añade). |
| `\|` | Tubería: salida estándar de una orden a la entrada de otra. |
| `\|&` | Salida estándar y de error a la siguiente orden. |
| `tee fichero` | Copia el flujo a un fichero y lo sigue pasando. |

```bash
cat /etc/passwd                          # entrada: el fichero; salida y errores: pantalla
cat > notas.txt                          # entrada: teclado; salida: notas.txt
ls /usr >> notas.txt                     # añade el listado a notas.txt
ls -R / 1> listado.txt 2> errores.txt    # listado por un lado, errores de permisos por otro
ls -1 . | wc -l                          # número de ficheros y directorios del directorio actual
ls -1 ~ | tee listado | wc -l            # guarda el listado y además cuenta las líneas
ls | tee prueba.txt | grep 'py'
```

## 3.7 Procesamiento de textos: `cut` y `grep`

### 3.7.1 `cut`

Imprime partes seleccionadas de cada línea. Si no se indica archivo, lee la entrada estándar. Sintaxis: `cut [opciones] fichero`.

- `-c lista`: selecciona caracteres.
- `-f lista`: selecciona campos; el delimitador se cambia con `-d`. **`-c` y `-f` no se pueden usar juntas.**

```bash
cut -f1 -d: /etc/passwd        # primer campo (nombre de usuario)
cut -f1,4-7 -d: /etc/passwd    # campos 1 y del 4 al 7
cut -c1-4,20 /etc/passwd       # caracteres 1 a 4 y 20
```

### 3.7.2 `grep`

Localiza un patrón en uno o varios ficheros y muestra las líneas que lo contienen. Sintaxis: `grep [opciones] patrón [fichero...]`.

| Opción | Efecto |
| :-: | --- |
| `-l` | Solo los nombres de fichero que contienen el patrón. |
| `-i` | No distingue mayúsculas/minúsculas. |
| `-c` | Número de líneas que cumplen el patrón por fichero. |
| `-w` | Patrón como palabra completa. |
| `-n` | Número de línea. |
| `-v` | Líneas que **no** contienen el patrón. |

## 3.8 Gestión de archivos por interfaz gráfica en Windows

El **Explorador de archivos**:

- **Barra de herramientas de acceso rápido:** se configura con el botón del triángulo.
- Se **adapta** a lo que se selecciona (unidad, carpeta o archivo) y a las operaciones posibles.
- **Cinta de opciones:**
  - Pestaña **Inicio:** copiar, pegar, mover, eliminar… (también con el botón derecho).
  - Pestaña **Compartir:** compartir el elemento de varias maneras.
  - Pestaña **Vista:** forma de organizar los elementos; la vista **Detalles** muestra más propiedades (se añaden o quitan con el botón secundario sobre la barra de detalles). El botón **Opciones** configura muchas características.
  - Pestaña **Herramientas de unidad** (al seleccionar una unidad): **cifrar**, **desfragmentar**, liberar espacio y **formatear**.
- Para mayor agilidad se usan combinaciones de teclas y teclas con el ratón.

> [!warning] Falta fuente: gestión de archivos en Windows por comandos y en Linux por entorno gráfico
> El Tema 3 no trae comandos de CMD/PowerShell para archivos (equivalentes de `ls`, `cp`, `mv`, `rm`…) ni el gestor de archivos gráfico de Linux (Dolphin en el openSUSE del aula, Nautilus/Archivos en GNOME).
