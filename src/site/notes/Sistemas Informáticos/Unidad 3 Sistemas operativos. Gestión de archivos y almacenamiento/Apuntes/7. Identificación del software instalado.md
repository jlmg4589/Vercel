# Unidad 3: Sistemas operativos. Gestión de archivos y almacenamiento

> [!abstract] Criterios que se trabajan
> **CE3G** (utilidades relacionadas con la gestión de información). Contenido **BC3_4** (identificación del software instalado mediante comandos y herramientas gráficas).

> [!warning] Falta fuente: identificación del software instalado
> Ni el Tema 3 ni los apartados asignados de los Temas 4 y 7 explican cómo listar el software instalado. Pendiente de material sobre:
> - **Linux (openSUSE):** comandos del gestor de paquetes y herramienta gráfica de YaST.
> - **Windows:** "Aplicaciones instaladas" de Configuración, "Programas y características" del Panel de control y comandos equivalentes.

## 7.1 Pistas que sí aparecen en las fuentes

- En la estructura de directorios, el software instalado se ubica en `/usr` (Linux) y en `\Archivos de programa` y `\Archivos de programa (x86)` (Windows): ver [[Sistemas Informáticos/Unidad 3 Sistemas operativos. Gestión de archivos y almacenamiento/Apuntes/2. Estructura de directorios en Linux y Windows\|2. Estructura de directorios en Linux y Windows]].
- Comprobar si un paquete está instalado en Debian/Ubuntu: `dpkg -l cron` (Tema 4, ver [[Sistemas Informáticos/Unidad 3 Sistemas operativos. Gestión de archivos y almacenamiento/Apuntes/9. Automatización y programación de tareas#9.1.3 `cron`\|cron]]).
- Instalar paquetes en Ubuntu: `sudo apt install mdadm`, `sudo apt install at`.
