# Unidad 3: Sistemas operativos. Gestión de archivos y almacenamiento

> [!abstract] Criterios que se trabajan
> **CE3C** (herramientas gráficas y comandos para localizar información). Contenido **BC3_3** (búsqueda de información del sistema mediante comandos y herramientas gráficas).

Los sistemas de archivos deben ofrecer herramientas para localizar archivos por distintos criterios (fecha, tamaño, nombre…) y para buscar dentro de su contenido. Para buscar **dentro** de los archivos se usa `grep` (ver [[Sistemas Informáticos/Unidad 3 Sistemas operativos. Gestión de archivos y almacenamiento/Apuntes/3. Gestión de archivos por comandos y entorno gráfico#3.7.2 `grep`\|grep]]).

## 6.1 Búsqueda por comandos en Linux: `find`

`find [ruta] [criterio] [acción]`

- Busca en la ruta o rutas dadas; sin ruta, en el **directorio actual**. Resultados y errores van a las salidas estándar.
- Sin criterio, no filtra.
- La **acción** permite tratar los ficheros encontrados.

### 6.1.1 Por nombre

| Opción | Efecto |
| --- | --- |
| `-name patrón` | Por nombre, admite patrones. |
| `-iname patrón` | Igual, sin distinguir mayúsculas. |

```bash
find ./ -name texto.txt
find ./ -name "t*.txt"     # empiezan por t y terminan en .txt
find ./ -iname texto.txt
```

### 6.1.2 Profundidad

La ruta indicada es la profundidad **0**; lo que contiene directamente, el **nivel 1**; lo que hay dentro de sus subdirectorios, el nivel 2, etc. (la fuente lo simplifica llamando "nivel 1" a la ruta).

| Opción | Efecto |
| --- | --- |
| `-maxdepth n` | Hasta qué nivel se busca. |
| `-mindepth n` | Desde qué nivel se empieza. |

```bash
find ./ -maxdepth 1 -name texto.txt               # solo el directorio actual
find ./ -maxdepth 2 -name texto.txt               # actual y subdirectorios
find ./ -mindepth 2 -name texto.txt               # desde los subdirectorios
find ./ -maxdepth 2 -mindepth 2 -name texto.txt   # solo los subdirectorios
```

### 6.1.3 Tiempos de acceso y modificación

Prefijo **`m`** (modificación del contenido) o **`a`** (acceso), con sufijo **`min`** (minutos) o **`time`** (días): `-mmin`, `-mtime`, `-amin`, `-atime`. Valores: `+n` mayor que, `-n` menor que, `n` igual.

```bash
find . -amin -1     # accedidos hace menos de un minuto
find . -mtime -1    # modificados hace menos de un día
```

> [!note] Tiempo de cambio
> El título de la fuente habla de "acceso, modificación y cambio", pero solo desarrolla `m` y `a`. El prefijo **`c`** (`-cmin`, `-ctime`) se refiere al **cambio de estado del i-nodo** (permisos, propietario, enlaces, o el propio contenido), no a la creación del archivo. En `-mtime`/`-atime`/`-ctime` los días se cuentan en periodos completos de 24 h (se descartan las fracciones).

> [!info] Fuentes
> - [find(1)](https://man7.org/linux/man-pages/man1/find.1.html)

### 6.1.4 Comparación con otro fichero

| Opción | Efecto |
| --- | --- |
| `-newer fichero` | Modificados más recientemente que *fichero*. |
| `-anewer fichero` | Accedidos más recientemente que la modificación de *fichero*. |

```bash
find . -anewer notas.txt
```

### 6.1.5 Tamaño

`-size n[unidad]` con `+n`, `-n` o `n`. Unidades: `b` (bloques de 512 bytes), `c` (bytes), `k` (KiB), `M` (MiB), `G` (GiB). El tamaño se **redondea hacia arriba** a la unidad: `-size -1M` solo encuentra ficheros vacíos.

```bash
find . -size +1M    # mayores de 1 MiB
```

### 6.1.6 Tipo

`-type` con `l` (enlace simbólico), `d` (directorio), `f` (regular), `b` (bloque), `c` (carácter).

```bash
find ./Escritorio -type d
```

### 6.1.7 Permisos

`-perm [-|/]permisos`, en octal o simbólico (ver [[Sistemas Informáticos/Unidad 4 Sistemas operativos. Gestión de usuarios y procesos/Apuntes/3. Permisos locales, máscara y perfiles de usuario#3.3 Modificación de permisos. chmod\|UD4: chmod]]).

| Forma | Significado | Ejemplo de la fuente |
| --- | --- | --- |
| `-perm 644` | Permisos **idénticos**. | Solo archivos `rw-r--r--`. |
| `-perm -644` | **Al menos** esos permisos. | Se suman los directorios `nivel2` y `nivel3` (`rwxr-xr-x`). |
| `-perm /644` | **Alguno** de esos permisos. | Los mismos: todos tienen `rw-` en usuario, `r` en grupo o `r` en otros. |

### 6.1.8 Otras opciones y combinación de criterios

| Opción | Efecto |
| --- | --- |
| `-user usuario` | Por propietario. |
| `-inum inodo` | Por número de i-nodo. |
| `-uid UID` | Por UID. |
| `-gid GID` | Por GID. |
| `-and`, `-a` | Deben cumplirse ambos criterios. |
| `-or`, `-o` | Uno u otro. |
| `-not`, `!` | Niega el criterio. |

Los paréntesis para agrupar se **escapan** con `\`.

```bash
find ./nivel2 -perm /644 -a -type d
find ./nivel2 -perm /644 -o -perm 755
find ./ -size +1M -a \( -user root -o -user luis \)
```

## 6.2 Búsqueda por interfaz gráfica en Windows

El **cuadro de búsqueda** del Explorador de archivos busca desde la unidad o carpeta actual por criterios como fecha, modificación, tamaño o clase. Se pueden combinar criterios con los operadores lógicos **NOT**, **OR** y **AND**. La cinta **Herramientas de búsqueda** se habilita al situarse en el cuadro e iniciar una búsqueda con **Intro**.

> No hay fuente sobre la búsqueda del gestor de archivos de Linux (Dolphin/KFind en openSUSE) ni sobre `where`, `dir /s`, `findstr` o `Get-ChildItem` en Windows.
