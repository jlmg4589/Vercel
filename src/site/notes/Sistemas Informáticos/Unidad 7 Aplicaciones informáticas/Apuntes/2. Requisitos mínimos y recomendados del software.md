# Unidad 7: Aplicaciones informáticas

> [!abstract] Criterios que se trabajan
> **CE7B** (necesidades específicas de software en diferentes entornos productivos). Contenido **BC7_1** (requisitos del software).

## 2.1 Requisitos mínimos y recomendados

Los propietarios de aplicaciones y sistemas operativos indican dos niveles de requisitos:

| Tipo | Significado |
| :-: | --- |
| **Mínimos** | Lo imprescindible para que el software pueda **ejecutarse y usarse**. |
| **Recomendados** | Más acordes con la **eficiencia y la ligereza** del sistema cuando trabaja en condiciones de cierto estrés. |

Los requisitos suelen referirse al **hardware** necesario (procesador, memoria RAM, espacio en disco, tarjeta gráfica…) y al **sistema operativo** sobre el que se instalará la aplicación.

## 2.2 Ejemplos

La fuente muestra como ejemplos (en capturas) las fichas de requisitos de tres productos de entornos muy distintos:

| Producto | Entorno |
| :-: | --- |
| Firefox 70.0.1 | Navegador (usuario final) |
| Windows Server 2019 | Sistema operativo de servidor (empresa) |
| Fortnite: Salvar el mundo | Videojuego (exige gráficos) |

> [!warning] Falta fuente: valores concretos de los requisitos
> Las diapositivas solo contienen capturas de pantalla, que no están en el texto extraído ni en las imágenes del vault. Hay que consultar las páginas oficiales de cada producto.

> [!warning] Falta fuente: necesidades de software por entorno productivo (CE7B)
> El Tema 7 no analiza qué software necesita cada entorno productivo (oficina, industria, comercio, sanidad…). Solo los ejemplos de requisitos anteriores.
