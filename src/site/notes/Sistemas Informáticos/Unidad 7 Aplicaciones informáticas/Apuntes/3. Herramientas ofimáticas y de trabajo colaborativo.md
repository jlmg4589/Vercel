# Unidad 7: Aplicaciones informáticas

> [!abstract] Criterios que se trabajan
> **CE7C** (tareas de documentación con herramientas ofimáticas y de trabajo colaborativo). Contenido **BC7_2**.

## 3.1 Suites ofimáticas

Las aplicaciones ofimáticas se agrupan normalmente en **suites o paquetes ofimáticos**, orientados a las tareas de oficina más habituales:

- Elaboración de textos.
- Cálculos a partir de tablas de datos.
- Creación de presentaciones.
- Gestión de bases de datos.
- Planificación de proyectos.
- Diseño gráfico.

### 3.1.1 Microsoft Office

**Privativo**, disponible para Microsoft Windows y Mac OS.

| Aplicación | Función |
| :-: | --- |
| Word | Procesador de textos |
| Excel | Hoja de cálculo |
| Access | Gestor de bases de datos |
| PowerPoint | Editor de presentaciones |
| Outlook | Gestor de correo electrónico y agenda |
| Publisher | Diseño de publicaciones |

### 3.1.2 Apache OpenOffice y LibreOffice

Software **libre y de código abierto**, para Microsoft Windows, Mac OS y GNU/Linux. Comparten la mayoría de características y funcionalidades.

| Aplicación | Función |
| :-: | --- |
| Writer | Procesador de textos |
| Calc | Hoja de cálculo |
| Base | Gestor de bases de datos |
| Impress | Editor de presentaciones |
| Draw | Editor gráfico |
| Math | Editor de fórmulas matemáticas |

Licencias: **Apache OpenOffice** usa la **Apache License 2.0** (la LGPLv3 era la licencia del antiguo OpenOffice.org, antes de pasar a la Apache Software Foundation en 2011) y **LibreOffice** la **MPL 2.0** (con partes también bajo LGPLv3+). Ver [[Sistemas Informáticos/Unidad 7 Aplicaciones informáticas/Apuntes/1. Tipos de software y licencias#1.1.6 Mozilla Public License (MPL)\|MPL]].

## 3.2 Ofimática en la nube y trabajo colaborativo

Cada vez más se trabaja **en la nube** con aplicaciones de Google o con suites como **G Suite** (Google) y **Office 365** (Microsoft). Ventajas:

- Se pueden **compartir documentos y trabajar de forma simultánea** sobre ellos.
- Los documentos están siempre **disponibles desde cualquier lugar**.
- Integran otros servicios en la nube: correo electrónico, videoconferencias, desarrollo web…
- La **escalabilidad** es muy alta.

> [!note] Nombres actuales
> G Suite se llama **Google Workspace** desde octubre de 2020 y Office 365 se comercializa como **Microsoft 365** desde abril de 2020.

> [!warning] Falta fuente: herramientas de trabajo colaborativo
> Aparte de la nota anterior, el Tema 7 no desarrolla herramientas colaborativas (control de cambios y comentarios compartidos, wikis, gestores de tareas, plataformas como Teams…). Ver también [[Sistemas Informáticos/Unidad 7 Aplicaciones informáticas/Apuntes/4. Correo, mensajería, transferencia de ficheros y nube#4.4 Computación y almacenamiento en la nube\|computación en la nube]].

## 3.3 Procesadores de texto

Aplicaciones para trabajar con **documentos de texto**, que se pueden editar y formatear de forma rápida y cómoda. Permiten incorporar imágenes, gráficos, tablas, índices…

Formatos más usados: **.docx** (Office Open XML) y **.odt** (OpenDocument Text).

Manejo básico:

- Abrir, cerrar, crear y guardar documentos.
- Conocer la ventana del procesador: áreas, barras y botones.
- Moverse por el documento.
- Insertar, eliminar, cortar, copiar y pegar texto.
- Formato de página y de fuente.
- Formato de párrafo: numeración y viñetas, espaciados, alineaciones, sangrías y tabulaciones.
- Crear tablas.
- Generar tablas de contenido o sumario.
- Insertar imágenes, formas y otros objetos.
- Revisión ortográfica y comentarios.
- Imprimir con diferentes opciones.

## 3.4 Hojas de cálculo

Aplicaciones para **editar y manipular datos** mediante **fórmulas o funciones**. Están formadas por una tabla en la que la intersección de filas y columnas forma las **celdas**, donde se guardan datos (numéricos o alfanuméricos) y se aplican cálculos.

Permiten trabajar con **rangos de celdas**, aplicar formatos, imprimir de forma selectiva, generar gráficos y tablas, ordenar valores…

Formatos más usados: **.xlsx** (Office Open XML) y **.ods** (OpenDocument Spreadsheet).

Manejo básico:

- Abrir, cerrar, crear y guardar libros.
- Conocer la ventana: áreas, barras y botones.
- Moverse por un libro.
- Referenciar una celda y un rango de celdas.
- Conocer los tipos de valores.
- Formato de celdas y de datos.
- Usar fórmulas y funciones.
- Generar gráficos.
- Imprimir hojas de cálculo.

## 3.5 Software de presentación

Aplicaciones para crear documentos con **diapositivas**, pensados para guiar charlas y captar la atención del público. Permiten incorporar textos, imágenes, gráficos, enlaces o vídeos, y añadir animaciones, música o sonidos y transiciones entre diapositivas.

Formatos más usados: **.pptx** (Office Open XML) y **.odp** (OpenDocument Presentation).

Manejo básico:

- Abrir, cerrar, crear y guardar presentaciones.
- Conocer la ventana: áreas, barras y botones.
- Insertar, eliminar y mover diapositivas.
- Usar plantillas.
- Organizar los elementos de una diapositiva: texto, imágenes, enlaces, tablas y objetos multimedia.
- Configurar la presentación: transiciones y música.
- Opciones de impresión.

## 3.6 Sistemas gestores de bases de datos

Aplicaciones para el **tratamiento, administración y gestión** de bases de datos. Permiten **definir, manipular y consultar** datos.

> [!note] Base de datos
> Es toda la información de una organización almacenada de forma **organizada y estructurada** para su explotación, formada por uno o varios archivos. Se estructura en **tablas relacionadas**, fruto de un diseño previo llamado **modelo entidad-relación**.

Formatos más usados: **.accdb** (formato propio y privativo de Access desde Access 2007, sustituto de .mdb; **no** forma parte de Office Open XML) y **.odb** (OpenDocument Database).

Manejo básico:

- Abrir, cerrar, crear y guardar bases de datos.
- Conocer la ventana: áreas, barras y botones.
- Crear, eliminar y editar tablas.
- Insertar y editar datos en tablas.
- Relacionar tablas entre sí.
- Realizar consultas simples de selección.
- Crear formularios.
- Generar informes.
- Imprimir formularios e informes.

## 3.7 Resumen de formatos

| Tipo de documento | Microsoft Office | OpenDocument (LibreOffice/OpenOffice) |

| Texto | .docx | .odt |
| Hoja de cálculo | .xlsx | .ods |
| Presentación | .pptx | .odp |
| Base de datos | .accdb | .odb |
