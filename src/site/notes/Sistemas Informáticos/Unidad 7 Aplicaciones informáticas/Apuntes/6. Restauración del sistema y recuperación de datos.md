# Unidad 7: Aplicaciones informáticas

> [!abstract] Criterios que se trabajan
> **CE7G** (herramientas de propósito general). Contenido **BC7_3** (recuperación de datos, mantenimiento del sistema).

## 6.1 Herramientas de copia, restauración y recuperación

Hay herramientas que facilitan las tareas sobre el sistema y los datos:

- Copia de seguridad de todo el sistema.
- Aseguramiento de los datos.
- Recuperación, reinicio y restauración.

Causas por las que hay que restaurar el sistema:

- Errores irrecuperables del sistema operativo.
- Eliminaciones o accesos malintencionados.
- Mal funcionamiento de una aplicación.
- Rotura de un medio de almacenamiento o inconsistencia de sus datos.
- Descuidos personales.
- Malware (ver [[Sistemas Informáticos/Unidad 7 Aplicaciones informáticas/Apuntes/5. Software antimalware y tipos de malware\|5. Software antimalware y tipos de malware]]).

## 6.2 Recuperación de datos

### 6.2.1 Por qué se pueden recuperar los datos

Los **bloques de datos** están físicamente en lugares distintos a su **índice**:

| Sistema de archivos | Índice |
| :-: | --- |
| ext4 (Linux) | i-nodo |
| NTFS (Windows) | MFT (*Master File Table*) |

Cuando se borra un archivo, el sistema de archivos solo **marca sus bloques como espacio libre**; los datos quedan inalterados y **recuperables mientras no se sobrescriban**.

> [!warning] Discos SSD
> En un **SSD con TRIM** activo (lo habitual hoy), el sistema avisa al disco de los bloques borrados y este los libera internamente en poco tiempo, por lo que la recuperación con software casi nunca es posible. Lo anterior se aplica sobre todo a discos duros (HDD) y memorias USB.

### 6.2.2 Cómo actuar

1. **Limitar al mínimo el uso** del medio afectado, inmediatamente, para evitar sobrescrituras.
2. Ejecutar un **software de recuperación** o pedir ayuda a una **empresa especializada**.

> [!tip] Recupera en otro disco
> Lo recuperado debe guardarse en otro medio distinto del afectado, para no sobrescribir lo que aún se quiere recuperar.

### 6.2.3 Programas de recuperación

Los más utilizados según la fuente:

- Recuva
- EaseUS Data Recovery
- Disk Drill
- Wise Data Recovery

> [!warning] Falta fuente: recuperación en Linux
> Los programas citados son para Windows (Disk Drill también para Mac). La fuente no trae herramientas para Linux/openSUSE (p. ej., TestDisk/PhotoRec).
