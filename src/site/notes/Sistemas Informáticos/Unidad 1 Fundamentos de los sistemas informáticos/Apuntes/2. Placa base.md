# Unidad 1: Fundamentos de los sistemas informáticos

> [!abstract] Criterios que se trabajan
> **CE1A** (componentes físicos y mecanismos de interconexión). Contenidos **BC1_1** (placas base, formatos) y **BC1_2** (interfaces de E/S).

## 2. Placa base

También llamada *motherboard*, es el **circuito impreso principal** del sistema: conecta todos los componentes hardware.

## 2.1 Factores de forma

Los estándares de factor de forma determinan las medidas, la disposición de los componentes (zócalos, conectores, buses de expansión), la potencia, la posición de los anclajes, etc.

| Factor de forma | Características |
| --- | --- |
| **ATX** | El más utilizado. Mejora la refrigeración respecto a sus antecesoras **AT** y **XT**. |
| **Micro-ATX / Mini-ATX** | Variantes reducidas de ATX con menos capacidad de expansión, para equipos de tamaño y prestaciones más reducidos. |
| **E-ATX** | Lo opuesto: equipos de alto rendimiento. |
| **ITX** (Mini-ITX, Nano-ITX, Pico-ITX) | Muy bajo consumo y dimensiones reducidas. Casi todo integrado, poca expansión; pueden carecer de refrigeración activa. |

## 2.2 Componentes de la placa base

Chipset, zócalo del microprocesador, ranuras de memoria RAM, ranuras de expansión, BIOS, conectores internos y conectores externos.

### 2.2.1 Chipset

Conjunto (*set*) de circuitos integrados (*chips*) que gestiona todos los componentes de la placa, dándoles sincronismo a través de los buses. Tradicionalmente lo forman dos chips:

- **Puente norte:** comunica el microprocesador con la memoria o el sistema gráfico. Hoy está **integrado en el microprocesador**.
- **Puente sur:** comunica el resto de puertos internos y externos. Actualmente **PCH** (*Platform Controller Hub*) en Intel y **Chipset** en AMD.

El chipset determina el procesador y la memoria RAM que se pueden instalar, los buses disponibles para ranuras de expansión, el número y tipo de conectores, la capacidad de *overclocking*, etc.

### 2.2.2 Zócalo del microprocesador (*socket*)

| Tipo | Descripción |
| --- | --- |
| **ZIF / PGA** (*Pin Grid Array*) | Zócalo de plástico con agujeros donde se insertan las **patillas** del microprocesador; una palanca permite encajarlo sin presión. |
| **LGA** (*Land Grid Array*) | Base de **contactos** sobre la que cierra una ventana metálica. El procesador no tiene patillas: menos riesgo de dañarlo y más contactos. |

### 2.2.3 Ranuras de memoria RAM

Alojan los módulos de RAM. Tienen una marca para alinear el módulo y anclajes laterales. Se agrupan por **colores** (parejas, tríos o cuartetos) para usar la tecnología de **doble, triple o cuádruple canal** (*dual channel*…), con acceso simultáneo a varias memorias.

### 2.2.4 Ranuras de expansión

Alojan las tarjetas de expansión. El bus más empleado es **PCI Express (PCIe)**, con hasta 16 líneas (*lanes*). La especificación PCIe 7.0 (128 GT/s por línea) se publicó en junio de 2025.

Anchos de banda aproximados **por sentido** (en ambos sentidos a la vez, el doble):

| Ranura | PCIe 4.0 (16 GT/s) | PCIe 7.0 (128 GT/s) |
| :-: | :-: | :-: |
| x1 | ≈ 2 GB/s | ≈ 16 GB/s |
| x4 | ≈ 8 GB/s | ≈ 64 GB/s |
| x16 | ≈ 32 GB/s | ≈ 256 GB/s |

Cada generación duplica la velocidad de la anterior y el ancho de banda crece en proporción al número de líneas.

Admiten tarjetas gráficas, de sonido, almacenamiento secundario, adaptadores de red, etc.

### 2.2.5 BIOS

Chip que se encarga de:

- Comprobar el hardware y lanzar el arranque.
- Realizar funciones básicas de E/S con el sistema operativo en marcha.
- Configurar el equipo mediante la **BIOS Setup Utility**.

Muchas placas tienen **dos BIOS** por seguridad. La configuración (fecha y hora, medios de arranque, periféricos, buses, *overclocking*…) se guarda en la **RAM-CMOS**, volátil, por lo que la placa lleva una **pila** para conservarla. Más detalles en [[Sistemas Informáticos/Unidad 1 Fundamentos de los sistemas informáticos/Apuntes/5. Puesta en marcha del equipo. POST\|5. Puesta en marcha del equipo. POST]].

## 2.3 Conectores internos

Interfaces físicas (puertos, ranuras y cables) dentro de la caja. Permiten la **transferencia de datos** y la **distribución de energía** entre componentes.

| Conector | Uso |
| --- | --- |
| **Ventiladores** | Ventilador del procesador y otros ventiladores de refrigeración. |
| **M.2** | Almacenamiento (SSD) o conectividad en equipos reducidos. Trabaja con buses **SATA** o **PCIe** según su *key ID*. |
| **SATA** | Datos entre el chipset y el almacenamiento secundario. Sustituyó a IDE. |
| **IDE** | Antiguo: discos duros y unidades CD-ROM/DVD. Sustituido por SATA. |
| **USB internos** | Conectan la placa con los USB del panel de la caja. |
| **Panel frontal** | Botón de encendido, botón de *reset*, LED de encendido, LED de uso de disco. |
| **Alimentación** | 20 o 24 pines para la placa base y 4 u 8 pines para el procesador. |

## 2.4 Conectores externos

Sirven para conectar periféricos.

| Conector | Uso |
| --- | --- |
| **eSATA** | Almacenamiento externo. |
| **Thunderbolt** | Alta velocidad (40 Gbit/s en Thunderbolt 3/4; 80 Gbit/s, hasta 120 en modo *Bandwidth Boost*, en Thunderbolt 5), basado en PCIe y DisplayPort; usa conector USB-C y cable de cobre. Almacenamiento y vídeo. |
| **Vídeo** | D-Sub (VGA), DVI, DisplayPort y HDMI (los dos últimos también transmiten audio). |
| **USB** | Ratón, teclado, almacenamiento, etc. |
| **Ethernet LAN (RJ45)** | Red por cable de par trenzado (ver [[Sistemas Informáticos/Unidad 1 Fundamentos de los sistemas informáticos/Apuntes/6. Tipos de cableado y conectores\|6. Tipos de cableado y conectores]]). |
| **Audio Jack / S/PDIF** | Sonido analógico / digital. |
| **PS/2** | Teclado y ratón; no admite conexión en caliente (*hot-plug*). |
