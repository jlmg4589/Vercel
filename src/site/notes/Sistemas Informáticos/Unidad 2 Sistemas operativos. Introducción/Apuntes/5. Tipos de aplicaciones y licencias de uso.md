## 5.1 Software y ejecución de programas

El Tema 1 añade la definición de **software** (programa o aplicación): conjunto de instrucciones que, al ejecutarse, llevan a cabo una o varias tareas con un fin común (procesador de texto, hoja de cálculo, juegos…). La ejecución de un programa por el procesador se describe en la UD1: [[Sistemas Informáticos/Unidad 1 Fundamentos de los sistemas informáticos/Apuntes/1. Sistema informático y arquitectura de los ordenadores#1.2.6 Ciclo de ejecución de un programa\|Ciclo de ejecución de un programa]].

| --- | :-: | --- |
| Windows / Windows Server | Propietario | Licencia de pago con restricciones del propietario |
