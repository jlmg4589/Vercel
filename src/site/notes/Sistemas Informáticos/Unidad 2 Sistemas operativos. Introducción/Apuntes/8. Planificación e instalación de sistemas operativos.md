# Unidad 2: Sistemas operativos. Introducción

> [!abstract] Criterios que se trabajan
> **CE2D** (planificar la instalación), **CE2E** (instalar SO libres y propietarios) y **CE2G** (instalar en máquinas virtuales). Contenidos **BC2_6**, **BC2_9** y **BC2_10**.

La instalación de un SO es **crítica**, porque se sustenta en el hardware y el firmware del sistema. El rendimiento óptimo del SO es consecuencia de una buena instalación.

## 8.1 Requisitos

Cada SO establece unos **requisitos mínimos** para poder ejecutarse y usarse y, además, unos **requisitos recomendados**, pensados para que el sistema sea eficiente y ligero en condiciones de cierto estrés.

## 8.2 Planificación y consideraciones previas

1. Comprobar que el equipo **cumple los requisitos** del SO.
2. Hacer una **copia de seguridad** de los datos que se quieran conservar.
3. **Diseñar el proceso de arranque**, sobre todo si habrá más de un SO (ver [[Sistemas Informáticos/Unidad 2 Sistemas operativos. Introducción/Apuntes/6. Arranque del sistema operativo y gestores de arranque\|6. Arranque del sistema operativo y gestores de arranque]]).
4. Disponer, en lo posible, de **alimentación eléctrica redundante**.
5. Reunir los componentes software pre y postinstalación:
   1. **Imagen** del SO.
   2. **Drivers** de todos los componentes hardware.
   3. **Aplicaciones** a instalar después del SO.
   4. Cambiar el **orden de arranque** para detectar el gestor de arranque deseado.
6. Establecer un **esquema de particiones** compatible con el firmware (BIOS o UEFI) y con el SO: **GPT (UEFI)** o **MBR (BIOS tradicional)**.

## 8.3 Instalación de Ubuntu en Oracle VM VirtualBox

1. **Crear la MV** con requisitos suficientes según el desarrollador (ver [[Sistemas Informáticos/Unidad 2 Sistemas operativos. Introducción/Apuntes/7. Virtualización e hipervisores#Crear una máquina virtual\|Crear una máquina virtual]]).
2. Comprobar que la **unidad óptica** va **antes que el disco duro** en el orden de arranque.
3. **Lanzar la MV** (doble clic) e indicar la ubicación de la **imagen ISO**.
4. Aparece un mensaje sobre la **integración de teclado y ratón** con la MV.
5. Elegir **idioma** y **tipo de instalación**:
   - "**Instalación normal**", si la RAM y el disco son suficientes.
   - Marcar "**Instalar programas de terceros para hardware de gráficos y de Wi-Fi y formatos multimedia adicionales**" si se usa una tarjeta de red o gráfica poco habitual o muchos formatos multimedia.
6. En el tipo de instalación sobre la partición, elegir "**Más opciones**" para particionar **manualmente**. Particiones recomendadas en Linux:

| Punto de montaje | Uso |
| :-: | --- |
| `/` | Sistema raíz |
| `swap` | Memoria de intercambio (ver [[Sistemas Informáticos/Unidad 2 Sistemas operativos. Introducción/Apuntes/2. Funciones y gestión de recursos del sistema operativo#2.5.2 Gestión de memoria\|memoria virtual]]) |
| `/home` | Datos de los usuarios |

7. Introducir las **credenciales** del usuario.
8. Al terminar, **Reiniciar** y extraer el disco si no se hace automáticamente. Primer inicio de sesión.

> [!note] Tamaños orientativos de las particiones
> La fuente no indica tamaños. Como orientación: `/` al menos **25 GB** (espacio mínimo que pide Ubuntu Desktop); `swap` según la RAM, aproximadamente igual a la RAM si se quiere **hibernar** y algo menor si no (con mucha RAM basta con unos pocos GB; Ubuntu usa por defecto un **archivo** de intercambio en lugar de partición); `/home`, el resto del disco. En UEFI/GPT hace falta además la **partición de sistema EFI** (ESP, FAT32, montada en `/boot/efi`).
>

> > - [Ubuntu – Requisitos de instalación](https://ubuntu.com/download/desktop)
> > - [Ubuntu – SwapFaq](https://help.ubuntu.com/community/SwapFaq)
