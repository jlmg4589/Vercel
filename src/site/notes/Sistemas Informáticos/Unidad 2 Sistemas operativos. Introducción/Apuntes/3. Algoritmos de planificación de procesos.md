# Unidad 2: Sistemas operativos. Introducción

> [!abstract] Criterios que se trabajan
> **CE2B** (funciones de un sistema operativo: gestión de procesos). Contenido **BC2_2**.

Dentro de la [[Sistemas Informáticos/Unidad 2 Sistemas operativos. Introducción/Apuntes/2. Funciones y gestión de recursos del sistema operativo#2.5.1 Gestión de procesos\|gestión de procesos]], el planificador decide qué proceso usa la CPU según un **algoritmo de planificación**.

## 3.1 Definiciones

**Datos de partida** de cada proceso:

| Símbolo | Nombre | Significado |
| :-: | --- | --- |
| $T_i$ | Tiempo de entrada o llegada | Momento en que el proceso entra en el sistema. |
| $T_x$ | Tiempo de ejecución | Tiempo que necesita el proceso para ejecutarse completo. |

**Datos que se calculan:**

| Símbolo | Nombre | Significado |
| :-: | --- | --- |
| $T_R$ | Tiempo de respuesta o de retorno | Desde que el proceso llega al sistema hasta que se obtienen los resultados. |
| $T_E$ | Tiempo de espera | Tiempo que el proceso pasa en el sistema esperando. |

Además se calculan los **tiempos medios** de respuesta y de espera, para valorar si un algoritmo es más o menos óptimo para unos datos de entrada.

**Fórmulas** ($T_{fin}$: instante en que termina el proceso; $n$: número de procesos):

$$T_R = T_{fin} - T_i \qquad T_E = T_R - T_x \qquad \overline{T_R} = \frac{\sum T_R}{n} \qquad \overline{T_E} = \frac{\sum T_E}{n}$$

> [!info] Fuentes
> - [Wikipedia – Turnaround time](https://en.wikipedia.org/wiki/Turnaround_time) (tiempo de retorno = finalización − llegada; espera = retorno − ráfaga)

## 3.2 Algoritmos

| Algoritmo | Criterio de selección | Expulsivo | Empates | Favorece / perjudica |
| --- | --- | :-: | :-: | --- |
| **FIFO / FCFS** | Orden de llegada | No | — | Atiende por orden. |
| **SJF** | El proceso **más corto** en espera | No | FIFO | Favorece a los procesos cortos. |
| **SRTF** | El que tiene **menos tiempo restante** | Sí | FIFO | Favorece a los cortos y mejora los tiempos medios; perjudica a los largos. |
| **Prioridades** | Mayor prioridad | Ambas variantes | FIFO | Optimiza el tiempo de respuesta de los más prioritarios. |
| **Rondas (*Round Robin*)** | Turno FIFO con *quantum* $q$ | Sí (implícito) | — | Reparte la CPU entre todos. |

### 3.2.1 FIFO (*First Input First Output*) o FCFS (*First Come First Served*)

Los procesos se ejecutan **en orden de llegada**. El primero que llega empieza a ejecutarse y los demás esperan su turno.

### 3.2.2 SJF (*Shortest Job First*): primero el más corto

Elige el proceso **más corto** de los que esperan la CPU. A igual tiempo, se aplica FIFO. Favorece a los procesos que tardan menos.

### 3.2.3 SRTF (*Shortest Remaining Time First*): primero el tiempo restante más corto

Elige el proceso en espera al que **le queda menos tiempo** para terminar; en empate, FIFO. Es **expulsivo**: si llega un proceso con menos tiempo restante que el que ocupa la CPU, lo desplaza (**cambio de contexto**). Favorece a los procesos cortos y mejora los tiempos medios, pero perjudica a los que necesitan más tiempo.

### 3.2.4 Por prioridades

Cada proceso tiene una **prioridad**; entran en la CPU por prioridad y, en empate, por FIFO.

- Puede ser **expulsivo** o **no expulsivo**.
- La prioridad puede cambiar: aumentarla a medida que el proceso espera, para evitar que los poco prioritarios se posterguen indefinidamente.
- Se indica con un **entero**: cuanto **más bajo**, **más prioritario**. Varios procesos pueden tener la misma prioridad.
- No favorece a procesos largos ni cortos: optimiza el tiempo de respuesta de los más prioritarios.

### 3.2.5 Por rondas (*Round Robin*)

Da tiempo de ejecución a cada proceso en espera durante un ***quantum*** ($q$); al agotarlo, abandona la CPU y pasa el siguiente en orden FIFO. Requiere un **cambio de contexto muy rápido**. Si no hay procesos en espera, el actual sigue hasta que llegue alguno. Es expulsivo de forma implícita.
