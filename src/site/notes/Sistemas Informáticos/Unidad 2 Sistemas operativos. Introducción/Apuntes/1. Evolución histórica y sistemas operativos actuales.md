# Unidad 2: Sistemas operativos. Introducción

> [!abstract] Criterios que se trabajan
> **CE2C** (comparar sistemas operativos por características, campos de aplicación y licencias). Contenidos **BC2_1** y, en parte, **BC2_10** (versiones).

Los sistemas operativos son una parte muy importante de los sistemas informáticos: son el software que permite trabajar con los equipos, **gestionando eficientemente sus recursos**. Están presentes en cualquier dispositivo, cada uno con su arquitectura.

## 1.1 Generaciones de ordenadores

| Generación | Periodo | Características |
| :-: | :-: | --- |
| 1.ª | 1940 – finales de los 50 | **Válvulas de vacío**. Uso científico o militar. |
| 2.ª | 1960 – 1965 | **Transistor**: ordenadores más pequeños y económicos. Programación en lenguaje máquina. |
| 3.ª | 1966 – 1971 | **Circuitos integrados** o chips (miniaturización de transistores). Surgen lenguajes como BASIC, C o Pascal. |
| 4.ª | 1971 – 1981 | Alta integración: **microprocesadores** (elementos básicos del ordenador en un solo circuito). |
| 5.ª | 1981 – actualidad | Comienza con la comercialización del **primer PC de IBM**. Surge la programación **orientada a objetos** (Java). |

## 1.2 Sistemas operativos más utilizados

### 1.2.1 Microsoft (propietarios)

**Escritorio (Windows):**

| Edición | Orientación |
| --- | --- |
| **Home** | Sobremesa, tablets o portátiles de poca potencia; uso básico (multimedia, ofimática y conectividad). |
| **Pro** | Negocios y profesionales. |
| **Enterprise** | Negocios (empresas). |
| **IoT** | Internet de las cosas. |
| **Pro for Workstations** | Equipos muy potentes con grandes cargas de trabajo intensivo o tareas críticas. |

**Servidor (Windows Server):**

| Edición | Orientación |
| --- | --- |
| **Datacenter** | Entornos en la nube o centros de datos altamente virtualizados. |
| **Standard** | Entornos poco virtualizados y con acceso a la nube. |
| **Essentials** | Pequeños negocios con número limitado de usuarios y dispositivos. |

### 1.2.2 GNU/Linux (libres)

Hay multitud de distribuciones, y de versiones de cada una:

| Ámbito | Distribución | Características |
| --- | --- | --- |
| Escritorio / portátil | **Ubuntu** y **Mint** | Genéricas y versátiles, muy fáciles de usar. |
| | **Arch Linux** | Personalizable, para usuarios avanzados. |
| | **Kali Linux** y **Tails** | Seguridad y privacidad. |
| | **Chromium OS** | Versión liberada de Chrome OS (SO en la nube de Google) con licencia **BSD** (libre, de código abierto y muy permisiva). |
| | **Manjaro** | Derivada de Arch Linux; facilidad de uso con modelo de **actualización continua**. |
| Servidor | Red Hat Enterprise Linux, Ubuntu Server, CentOS Stream, SUSE Linux Enterprise Server, Debian | — |

> [!note] FreeBSD, Chromium OS y CentOS
> - **FreeBSD** (que la fuente incluye aquí) **no es una distribución GNU/Linux**: es un sistema operativo libre de tipo Unix, descendiente de BSD, con su propio núcleo y licencia BSD. Se usa mucho en servidores.
> - **Chromium OS** sí usa el **kernel Linux**, pero no es una distribución GNU/Linux de propósito general: es la base abierta de Chrome OS.
> - **CentOS Linux** dejó de existir (CentOS 7 terminó su soporte el 30/06/2024); hoy el proyecto es **CentOS Stream**, rama previa a RHEL. Alternativas compatibles con RHEL: Rocky Linux y AlmaLinux.

> [!note] En el aula
> Se trabaja con **openSUSE** (familia de SUSE) sobre **VirtualBox**. La fuente no describe openSUSE.

### 1.2.3 Apple (propietarios)

- **macOS:** escritorio y portátiles.
- **macOS Server:** servidores. Apple lo **retiró en abril de 2022**; sus funciones de servidor están integradas en macOS.
- **iOS:** iPhone. Núcleo **híbrido** **XNU** (acrónimo de "X no es Unix"), que combina el micronúcleo **Mach** con partes de BSD.
- **iPadOS:** iPad. Derivado de iOS; desde 2019 el iPad tiene su propio sistema (la fuente lo sitúa bajo iOS).

### 1.2.4 Otros sistemas móviles y ligeros

| Sistema | Desarrollador | Características |
| --- | --- | --- |
| **Android** | Google | Núcleo **monolítico** basado en el kernel Linux. *Smartphones* y tablets. Libre y de código abierto: licencias **Apache 2.0** y **GNU GPLv2**. |
| **Chrome OS** | Google | Para ordenadores **Chromebook**; kernel Linux; pensado sobre todo para navegar por Internet. |
