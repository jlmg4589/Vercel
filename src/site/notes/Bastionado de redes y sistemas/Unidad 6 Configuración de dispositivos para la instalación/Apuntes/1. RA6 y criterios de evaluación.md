# Unidad 6: Configuración de dispositivos para la instalación de sistemas informáticos

**Evaluación:** 2ª evaluación.

> [!abstract] Resultado de aprendizaje RA6
> Configura dispositivos para la instalación de sistemas informáticos minimizando las probabilidades de exposición a ataques.
