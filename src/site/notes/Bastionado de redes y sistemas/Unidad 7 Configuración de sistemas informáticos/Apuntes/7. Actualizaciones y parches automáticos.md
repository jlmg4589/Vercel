# 7. Actualizaciones y parches automáticos

## 7.1 Importancia de las actualizaciones

Mantener actualizados el sistema operativo y las aplicaciones es **la mejor forma de prevenir y corregir vulnerabilidades**: el sistema tendrá siempre los últimos **parches de seguridad** y se evita que los atacantes exploten fallos conocidos, además de garantizar el funcionamiento óptimo del software.

- Todo el software debe estar actualizado, **sobre todo el sistema operativo y los programas que usamos en Internet**.
- Un equipo sin actualizar se expone a *exploits* como el de **WannaCry**.
- Se deben evitar **sistemas sin soporte** (Windows XP, Windows Server 2008, Windows 7), ya que dejan de recibir parches (ver [[Bastionado de redes y sistemas/Unidad 7 Configuración de sistemas informáticos/Apuntes/5. Securización de la administración remota#5.4.3 Securizar RDP\|Securizar RDP]]).

> [!important] Entornos corporativos y de producción
> - En una corporación es adecuado disponer de un **servidor de actualizaciones** que pruebe en **laboratorio** el impacto de los parches antes de instalarlos en producción.
> - En sistemas críticos puede ser necesario mantener una **réplica** e instalar primero en ella las actualizaciones, porque las más grandes pueden provocar fallos en alguna aplicación.

## 7.2 Windows Update

Microsoft publica actualizaciones **el segundo martes de cada mes** para todo su software con soporte, y los sistemas están configurados para **recibirlas e instalarlas automáticamente**. Es posible configurar cuándo recibirlas para evitar problemas.

Acceso: **Inicio → Configuración (rueda dentada) → Actualización y seguridad → Windows Update**.

- Se muestra el **estado** (si está actualizado y la última comprobación).
- Botón **Buscar actualizaciones**.
- Opciones de configuración y programación según nuestras necesidades.

> [!note]
> Windows **no permite deshabilitar** Windows Update, precisamente por la importancia de mantener el sistema al día.

## 7.3 Actualizaciones automáticas en GNU/Linux

> [!warning] Falta fuente: las fuentes no explican cómo configurar actualizaciones automáticas en GNU/Linux.

Referencia mínima para Debian/Ubuntu (conocimiento general, verificar):

```bash
sudo apt update && sudo apt upgrade            # actualización manual
sudo apt install unattended-upgrades
sudo dpkg-reconfigure --priority=low unattended-upgrades
# configuración en /etc/apt/apt.conf.d/50unattended-upgrades y 20auto-upgrades
```

> [!tip]
> Las herramientas de seguridad también deben actualizarse: por ejemplo, `sudo rkhunter --update` actualiza las firmas de Rootkit Hunter, y la eficacia de un antivirus depende de la frecuencia de actualización de su base de datos (ver [[Bastionado de redes y sistemas/Unidad 7 Configuración de sistemas informáticos/Apuntes/6. Prevención y protección frente a virus e intrusiones\|6. Prevención y protección frente a virus e intrusiones]]).
