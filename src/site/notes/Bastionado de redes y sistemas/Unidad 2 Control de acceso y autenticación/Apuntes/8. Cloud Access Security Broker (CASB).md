# 8. Cloud Access Security Broker (CASB)

## 8.1 Qué es un CASB

Un **Cloud Access Security Broker (CASB)**, o **Agente de Seguridad para el Acceso a la Nube**, es una de las tecnologías con mayor proyección. Es un **punto de control de visibilidad y de políticas** situado **entre los usuarios y las aplicaciones en la nube**.

Según **Gartner**, los CASB son puntos de aplicación de políticas de seguridad basados en la nube, situados entre los usuarios y los proveedores de servicios *cloud*, que garantizan que **solo los usuarios autorizados** acceden a los servicios. Ejemplos de estos puntos de control:

- Asignación de credenciales e inicio de sesión para la autenticación.
- Creación de perfiles de acceso.
- Registros.
- Tokenización y cifrado.
- Alertas de intentos de acceso no autorizado.
- Detección de *malware*.

## 8.2 Modos de implementación

1. Mediante una **puerta de enlace tipo *proxy***.
2. Mediante un **agente instalado en el *host***.
3. Mediante una **solución SaaS nativa basada en API**.

## 8.3 Los cuatro pilares del CASB

| Pilar | Qué aporta |
| --- | --- |
| **Visibilidad** | Qué aplicaciones (autorizadas o no) usan los empleados, con qué frecuencia y cuándo. |
| **Conformidad** | Saber si la organización cumple regulaciones como **HIPAA, PCI, FISMA**, mediante el gobierno de datos. |
| **Prevención de amenazas** | Analizar el comportamiento de usuarios internos y externos maliciosos para evaluar el riesgo (¿acceden usuarios de confianza a información que no deberían?). |
| **Seguridad de los datos** | Cifrado, tokenización y **prevención de pérdida de datos**: ¿qué datos se acceden y comparten?, ¿se comparten de forma perjudicial?, ¿se protege la propiedad intelectual? |
