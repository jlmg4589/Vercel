# 📝 Práctica: Configuración de seguridad de Windows y Linux

> [!note] Objetivos de la Práctica
> - Identificar las medidas para securizar un sistema Windows y un sistema Linux "de dentro a fuera".
> - Aplicar buenas prácticas y estándares de securización.

## 📐 Recordatorio Teórico
- [[Bastionado de redes y sistemas/Unidad 1 Diseño de planes de securización/Apuntes/6. Guía de buenas prácticas de securización\|6. Guía de buenas prácticas de securización]] (actualizaciones y aseguramiento del SO)
- [[Bastionado de redes y sistemas/Unidad 1 Diseño de planes de securización/Apuntes/5. Políticas de securización\|5. Políticas de securización]] (control de accesos, gestión de usuarios)
- [[Bastionado de redes y sistemas/Unidad 1 Diseño de planes de securización/Apuntes/4. Plan de medidas técnicas de seguridad\|4. Plan de medidas técnicas de seguridad]] (exposición de servicios, VPN, cifrado)

## 🛠️ Enunciado
Elabora un **informe** sobre cómo habría que configurar Windows y Linux para establecer su seguridad **de dentro a fuera**:

1. **Usuarios y permisos:** cuentas, privilegios mínimos, contraseñas.
2. **Sistema:** actualizaciones, servicios, ejecución automática, cifrado.
3. **Red y accesos desde el exterior:** acceso remoto, VPN, routers, etc.

Para cada punto indica la medida en Windows y en Linux.

**Criterio de evaluación asociado:** RA1 f).
